# Faraloca — GitHub Pages Portfolio

A responsive, static English–Indonesian translation portfolio built with HTML, CSS, and JavaScript. No database, backend, form submission, or build tools are required.

## Files
- `index.html` — page content
- `style.css` — responsive design
- `script.js` — mobile navigation, portfolio sample toggles, current year
- `assets/faraloca-logo-reference.jpg` — cropped reference of the selected middle logo from the provided concept image

## Preview locally
Double-click `index.html` to open it in a browser. Google Fonts requires an internet connection; the page itself otherwise uses local files.

## Publish with GitHub Pages
1. Create a **public** repository named `faraloca` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to complete. The expected URL format is `https://YOUR-USERNAME.github.io/faraloca/`.

If you instead name the repository `YOUR-USERNAME.github.io`, the site can be published at the root URL `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Replace `hello@example.com` in `index.html` with your real professional email address.
- Update the profile text to reflect your actual experience and skills.
- The portfolio examples are illustrative practice samples, not client work or official translations of copyrighted series.
- The included logo image is a cropped reference from the supplied logo concept image. For a production-quality header, replace it with a clean transparent PNG or SVG logo if available.
- Check that all public portfolio samples are original or authorized for publication.

## Limitations
This is a static reading portfolio. It does not store visitor data or process form submissions. The email link opens the visitor's default email application.
